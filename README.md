# Proyecto No-Country-CRM

Este es un CRM y una aplicación web en desarrollo para la simulación de No Country (S03-26-Equipo-17).

## Estructura del Proyecto

El proyecto se divide en los siguientes componentes principales:

*   **`frontend/`**: Interfaz de usuario construida con React, Tailwind CSS y Javascript.
*   **`backend/`**: Lógica de negocio y API desarrollada con Java y Spring Framework.
*   **`IA/`**: Componentes de IA y procesamiento de datos.

## Configuración y Setup

### Prerrequisitos

*   Node.js (v18+)
*   Java JDK 21+
*   Maven

### Instalación

1.  Clona el repositorio.
2.  Navega a la carpeta deseada (`frontend` o `backend`).
3.  Sigue las instrucciones específicas en los directorios correspondientes para iniciar los servicios.
